# Security Policy

## Supported Versions

The latest version has been uploaded; security issues in the current version can still be reported.

## Reporting Security Vulnerabilities

Please contact us to report information related to suspected security vulnerabilities. Please create a GitHub Issue.

Do not provide passwords, scepters, cookies, private files, or other sensitive information in public GitHub Issues.
