# 安裝與解除安裝人工測試清單

請使用一次性 Windows x64 測試帳戶或虛擬機器。請勿對真實使用者下載內容或恢復資料執行破壞性
檢查。

## 安裝

- [ ] 全新 per-user 安裝。
- [ ] 覆蓋既有版本升級安裝。
- [ ] 預設安裝位置為 `%LOCALAPPDATA%\Programs\HyperDL`。
- [ ] 自訂安裝位置可正常使用。
- [ ] 選取工作時建立桌面捷徑。
- [ ] 未選取工作時不建立桌面捷徑。
- [ ] 開始功能表 HyperDL 捷徑可啟動應用程式。
- [ ] 開始功能表 `Uninstall HyperDL` 捷徑可開啟受管理的解除安裝程式。
- [ ] HyperDL 顯示於 Windows「已安裝的應用程式」／「應用程式與功能」。
- [ ] 應用程式圖示、版本及發行者顯示正確。
- [ ] 已安裝應用程式檔案存在。
- [ ] 未安裝已移除的整合功能或主機檔案。

## 下載流程

- [ ] 新增直接 HTTP 網址。
- [ ] 新增直接 HTTPS 網址。
- [ ] Auto 連線模式。
- [ ] 固定連線模式。
- [ ] 暫停符合條件的分段下載。
- [ ] 繼續已暫停的下載。
- [ ] 取消下載並確認文件所述的部分檔案處理方式。
- [ ] 重新啟動應用程式並檢查當機恢復行為。
- [ ] 開啟選取的下載資料夾。
- [ ] 確認完成檔案及預期長度。

## 解除安裝

- [ ] 從 Windows 設定解除安裝。
- [ ] 從開始功能表捷徑解除安裝。
- [ ] 確認解除安裝確認對話框。
- [ ] 從安裝目錄移除程式檔案。
- [ ] 移除應用程式及解除安裝捷徑。
- [ ] 移除 Windows「已安裝的應用程式」項目。
- [ ] 保留已完成的使用者下載。
- [ ] 保留安裝目錄以外的 `.part` 檔案。
- [ ] 保留 `%LOCALAPPDATA%\HyperDL` 設定及歷史紀錄。
- [ ] 解除安裝後可重新安裝。
- [ ] 升級安裝正常運作。

## 選擇性完整移除本機資料

- [ ] 先備份所需下載及恢復資料。
- [ ] 正常解除安裝 HyperDL。
- [ ] 關閉所有 HyperDL 程序。
- [ ] 只有在確定要刪除設定、下載歷史及恢復 metadata 時，才手動移除
      `%LOCALAPPDATA%\HyperDL`。
- [ ] 個別檢查使用者選取下載資料夾內的 `.part` 檔案；刪除檔案會移除該工作的續傳資料。
- [ ] 確認未影響無關的使用者下載內容。
