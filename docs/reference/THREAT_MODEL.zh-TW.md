# 威脅模型

## 受保護資產

- 使用者檔案及下載目的地。
- SQLite 下載 metadata 及可續傳的 `.part` 暫存檔。
- 使用者憑證；應用程式不提供協定憑證欄位。

## 信任邊界

- 網路回應視為不受信任，會先寫入暫存檔再完成檔案處理。
- HTTP 要求使用平台預設的 TLS 憑證驗證。
- 下載器不會啟動下載的執行檔或指令碼。
- 下載歷史儲存於使用者本機應用程式資料目錄。

## 不支援範圍

不支援 DRM 規避、任意命令執行、遠端指令碼執行、BitTorrent、FTP/FTPS、外掛載入及自動更新。

## 剩餘風險

同時建立許多連線可能增加遠端伺服器負載；使用者應優先選擇 Auto，並遵守伺服器限流要求。
即使傳輸成功，下載檔仍可能有害；開啟前應確認來源並掃描檔案。
