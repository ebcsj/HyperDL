# BitTorrent status and legal use

BitTorrent and magnet support are not implemented, and no torrent engine or
Torrent Host is shipped.

If implemented later, it must only be used for content the user is authorized
to download or share. HyperDL must not add piracy search, private-tracker
credential extraction, automatic web magnet scanning, or automatic opening of
downloaded files. No claim of torrent resume, piece verification, or speed
limiting applies to this release.
