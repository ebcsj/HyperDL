# HyperDL 使用指南

[繁體中文](USER_GUIDE.md) | [English](USER_GUIDE.en.md)

HyperDL 是供 Windows 使用的桌面下載管理器，接受直接 HTTP 或 HTTPS 檔案網址。
它不會從影片網站擷取受保護串流，也不會自動執行已下載檔案。

## 安裝與啟動

1. 只從你信任的來源取得 HyperDL Setup。
2. 執行 `HyperDL_Setup.exe`，並按 Setup 指示完成安裝。不需要系統管理員權限；
   安裝器目前未簽署。
3. 從開始功能表啟動 HyperDL。
4. 若從原始碼執行，請在 Windows x64 安裝 .NET 8 SDK，再於專案根目錄執行：

   ```powershell
   dotnet run --project HyperDL.csproj
   ```

## 新增下載

1. 在 `URL` 欄輸入直接指向檔案的完整 `http://` 或 `https://` 網址。
   網頁、FTP 網址、磁力連結及需要瀏覽器登入的受保護內容不屬於支援範圍。
2. 選擇 `Auto` 或連線數。Auto 依已知檔案大小選擇目標；伺服器不支援
   byte ranges、檔案大小未知或太小時，HyperDL 會使用單一連線。
3. 按 `加入下載`。HyperDL 會先探測伺服器，再開始下載。
4. 在進度區及下載清單查看檔名、大小、百分比、速度、ETA、狀態和連線數。
   若伺服器沒有提供檔案總長度，總大小及百分比可能顯示為未知。
5. 完成後，檔案會存到設定中的下載資料夾；預設為目前 Windows 使用者的
   `Downloads` 資料夾。選取工作後可按 `開啟資料夾`。

檔名會優先採用伺服器提供的檔名，否則從網址路徑取得，並清理不安全字元。
若目標檔名已存在，HyperDL 會選用帶有序號的另一個檔名。

## 連線、暫停與取消

- 可選模式為 `Auto`、1、2、4、8、16、32 或 64。實際分段數受檔案大小、
  伺服器支援及全域連線上限限制；連線數較高不保證速度較快。
- `暫停` 和 `繼續` 僅適用於已確認 Range 支援且大小已知的分段下載。
  繼續前，HyperDL 會重新檢查來源資訊；來源大小或可用驗證資訊改變時會拒絕續傳。
- 單連線 fallback 不支援暫停或續傳。取消會停止工作並保留 `.part` 暫存檔，
  已取消的分段工作稍後仍可從清單續傳。
- 從清單移除工作會保留其 `.part` 檔。若要連同已下載與暫存資料一併刪除，
  請使用 `刪除檔案並移除`，並先確認該資料不再需要。

## 設定與下載紀錄

展開 `設定` 可設定預設下載資料夾、Auto/固定連線數、最大同時下載數、緩衝區模式
（`Auto`、`LowRam`、`Balanced`、`Fast`）、速度上限、動態分段與語言。緩衝區大小
受全域 64 MiB 網路緩衝預算限制；這不是整個應用程式的 RAM 上限。
最大同時下載設定會限制同時執行的工作數量。

設定檔位於 `%LOCALAPPDATA%\HyperDL\settings.json`。可恢復分段下載的 metadata
位於 `%LOCALAPPDATA%\HyperDL\hyperdl.db`；這個資料庫不保存檔案內容。
程式非預期關閉後，若已開啟自動續傳（預設開啟），啟動時會自動恢復已中斷與已暫停的
工作；也可在下載清單選取可恢復工作並按 `繼續`。恢復前會再次驗證來源。
單連線下載不會建立可恢復的工作階段。

一般解除安裝會移除應用程式本身，但保留使用者下載、`.part` 檔案及
`%LOCALAPPDATA%\HyperDL` 設定與歷史。手動刪除這些資料前請先備份。

## 系統匣、通知與其他功能

開啟「最小化到系統匣」（預設開啟）時，關閉或最小化 HyperDL 會隱藏到通知區。
雙擊系統匣圖示可還原視窗；系統匣右鍵選單提供全部暫停、全部繼續與結束。

開啟「顯示下載通知」時，下載完成或失敗會顯示通知。剪貼簿監看清單為 opt-in
（預設關閉）：啟用後複製的直接 HTTP/HTTPS 網址會填入網址框，按 Enter 即可加入；
「貼上」按鈕可手動執行相同動作。開啟「佇列完成時詢問是否關閉 Windows」且所有
佇列下載都已完成時，HyperDL 會先詢問確認才關機（可用 `shutdown /a` 取消）。

## 完整性、排程與其他功能

- 下載完成時 HyperDL 會計算其 SHA-256。右鍵工作選擇 `驗證 SHA-256…`，與下載
  來源提供的預期值比對；`複製 SHA-256` 可複製計算出的雜湊。
- 右鍵尚未開始的工作選擇 `排程…` 可設定未來開始時間（`yyyy-MM-dd HH:mm`）；
  留空即可清除排程。排程的工作會在佇列中等待到指定時間。
- 分段下載進行中，詳細資料區會顯示每段進度條。
- 設定中的「使用 HTTP/2」為實驗性，預設關閉；未啟用時使用 HTTP/1.1。
- 開啟「啟動時檢查 GitHub 是否有新版本」時，HyperDL 會比較最新 GitHub Release
  與自身版本，並在狀態列顯示連結；不會自動下載或安裝。

## 命令列、深色主題與維護

- `HyperDL.exe --list` 以 JSON 輸出下載佇列；`--pause-all`、`--resume-all`、
  `--clear-completed` 可控制執行中的執行個體；`--import <file>` 逐行批次加入
  網址。指令會與執行中的執行個體通訊，並在主控台輸出 JSON 回覆。
- 設定中的「深色主題」可即時切換介面並自動保存。
- 設定中的「匯出設定…」／「匯入設定…」以 JSON 在不同電腦間搬移設定。
- 在下載清單拖曳列即可調整佇列順序。
- 原生訊息（選用）：把擴充功能選項頁顯示的擴充功能 ID 貼入設定並啟用
  「原生訊息」，擴充功能即可免外部協定確認框直接交付連結；`hyperdl://`
  協定仍作為後備。

## 安全使用

只下載你有權取得的內容，並遵守網站條款及適用法律。不要將密碼、Cookie 或
Token 放入網址。下載完成的 EXE、MSI、BAT、CMD、PS1 或其他檔案不會由
HyperDL 自動執行；開啟前請確認來源並使用安全工具檢查。

需要協助時，請參閱[疑難排解](TROUBLESHOOTING.md)及
[系統架構](../ARCHITECTURE.md)。
