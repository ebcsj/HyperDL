# HyperDL 使用指南

[繁體中文](USER_GUIDE.md) | [English](USER_GUIDE.en.md)

HyperDL 是供 Windows 使用的桌面下載管理器，接受直接 HTTP 或 HTTPS 檔案網址。
它不會從影片網站擷取受保護串流，也不會自動執行已下載檔案。

## 安裝與啟動

1. 只從你信任的來源取得 HyperDL Setup。
2. 執行 `HyperDL_Setup.exe`，並按 Setup 指示完成安裝。不需要系統管理員權限；
   安裝器目前未簽署。
3. 從開始功能表啟動 HyperDL。
4. 若從原始碼執行，請在 Windows x64 安裝 .NET 8 SDK，再於專案根目錄執行：

   ```powershell
   dotnet run --project HyperDL.csproj
   ```

## 新增下載

1. 在 `URL` 欄輸入直接指向檔案的完整 `http://` 或 `https://` 網址。
   網頁、FTP 網址、磁力連結及需要瀏覽器登入的受保護內容不屬於支援範圍。
2. 選擇 `Auto` 或連線數。Auto 依已知檔案大小選擇目標；伺服器不支援
   byte ranges、檔案大小未知或太小時，HyperDL 會使用單一連線。
3. 按 `Start Download`。HyperDL 會先探測伺服器，再開始下載。
4. 在進度區及下載清單查看檔名、大小、百分比、速度、ETA、狀態和連線數。
   若伺服器沒有提供檔案總長度，總大小及百分比可能顯示為未知。
5. 完成後，檔案會存到設定中的下載資料夾；預設為目前 Windows 使用者的
   `Downloads` 資料夾。選取工作後可按 `開啟下載資料夾`。

檔名會優先採用伺服器提供的檔名，否則從網址路徑取得，並清理不安全字元。
若目標檔名已存在，HyperDL 會選用帶有序號的另一個檔名。

## 連線、暫停與取消

- 可選模式為 `Auto`、1、2、4、8、16、32 或 64。實際分段數受檔案大小、
  伺服器支援及全域連線上限限制；連線數較高不保證速度較快。
- `暫停` 和 `繼續` 僅適用於已確認 Range 支援且大小已知的分段下載。
  繼續前，HyperDL 會重新檢查來源資訊；來源大小或可用驗證資訊改變時會拒絕續傳。
- 單連線 fallback 不支援暫停或續傳。按取消會停止工作並清除此下載的不完整暫存內容。
- 刪除已暫停或可恢復的工作紀錄時，HyperDL 會詢問是否一併刪除其 `.part` 檔；
  請先確認該暫存資料不再需要。

## 設定與下載紀錄

展開 `設定` 可設定預設下載資料夾、Auto/固定連線數、最大同時下載設定、全域連線
上限及 Low RAM 模式。Low RAM 模式使用 64 KiB 網路緩衝區；一般模式使用
80 KiB。這不是整個應用程式的 RAM 上限。雖然可以儲存最大同時下載設定，佇列工作
目前仍依序執行。

設定檔位於 `%LOCALAPPDATA%\HyperDL\settings.json`。可恢復分段下載的 metadata
位於 `%LOCALAPPDATA%\HyperDL\hyperdl.db`；這個資料庫不保存檔案內容。
遇到程式非預期關閉後，可在下載清單選取可恢復工作並按 `繼續`。恢復前會
再次驗證來源。單連線下載不會建立可恢復的工作階段。

一般解除安裝會移除應用程式本身，但保留使用者下載、`.part` 檔案及
`%LOCALAPPDATA%\HyperDL` 設定與歷史。手動刪除這些資料前請先備份。

## 安全使用

只下載你有權取得的內容，並遵守網站條款及適用法律。不要將密碼、Cookie 或
Token 放入網址。下載完成的 EXE、MSI、BAT、CMD、PS1 或其他檔案不會由
HyperDL 自動執行；開啟前請確認來源並使用安全工具檢查。

需要協助時，請參閱[疑難排解](TROUBLESHOOTING.md)及
[系統架構](../ARCHITECTURE.md)。
